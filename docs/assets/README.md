# Assets

## phantom/

Grey-scale slices rendered from the synthetic lumbar phantom (`spinescope.testing.phantom`, no patient or
public-dataset image is involved). Each file is one 2-D slice, upscaled 2x for reading.

| file | what |
|---|---|
| `realistic_sag_t2.png`, `realistic_sag_t1.png`, `realistic_sag_stir.png` | midline sagittal, `realism="realistic"` (T2 spin echo, T1 spin echo, STIR) |
| `realistic_ax_L4_t2.png` | axial at the L4 body, T2 spin echo (psoas, paraspinal muscles with fat streaks, bowel, aorta and IVC) |
| `realistic_ax_S1_t1.png` | axial at the S1 body, T1 spin echo (iliac wings, sacrum) |
| `cartoon_sag_t2.png`, `cartoon_sag_t1.png`, `cartoon_sag_stir.png` | the same midline views of the default cartoon phantom, for comparison |

Source: `docs/labeling/lab21_phantom.md` (generated by `spinescope.testing.phantom` with default seed 0; the
parameters are in the doc). Images contain no real patient data and no fake PHI.

## viewer/

Screenshots of the viewer's label tools (`docs/guide/correcting-labels.md`), taken from the synthetic lumbar phantom
(`spinescope.testing.phantom`, 1.5 mm pixels, default seed; no patient or public-dataset image is involved). The page
title says "Synthetic lumbar phantom (no patient data)".

| file | what |
|---|---|
| `01_auto_labels.jpg` | the viewer with the automatic labels; the banner says unconfirmed |
| `02_shift_applied.jpg` | after "Shift all labels up 1" with a reason; still not confirmed |
| `03_add_disc_placed.jpg` | the missed L5-S1 placed by a click on the sagittal pane |
| `04_confirmed.jpg` | after "Confirm levels" |
| `05_findings_panel.jpg` | the findings panel (right) with a disc contour finding selected: the table, the level status and the three planes moved to the level, markers on the slices |
| `06_findings_experimental.jpg` | the same panel with an experimental Modic-type suggestion selected: its note under the row, the `experimental` badge and the dashed marker convention |

The findings screenshots come from the phantom with planted pathology (`tools/viewer_screenshots.py`: a degenerated
L4-L5 disc, a Modic-1-like marrow change under the left inferior L4-L5 endplate, a 5 mm central L5-S1 herniation).
Every finding shown is an analysis output on that phantom, not a check against ground truth. The page title says
"Synthetic lumbar phantom (no patient data)".
